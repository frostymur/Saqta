> **Digital Urpaq 2026**

## 🌊 О платформе Saqta.kz

**Saqta.kz** («Сақта» — каз. *сохранять, беречь*) — официальный предиктивный портал гражданской защиты Республики Казахстан. Создан для оперативного, человекоцентричного информирования жителей о паводковой обстановке, заблаговременного предупреждения об эвакуации и предоставления проверенных каналов экстренной помощи.

В отличие от перегруженных операторских панелей, портал спроектирован по **стандартам GovTech KZ**:
- **Цветовая система:** Белая основа, спокойная еловая зелень (`#064E3B`), глубокий речной синий (`#0369A1`), мягкая статусная палитра МЧС РК.
- **Типографика:** Humanist-гротеск **Onest** (разработан специально для комфортного чтения больших массивов данных на экранах).
- **Ответ на 4 главных вопроса гражданина при ЧС:**
  1. *Какова ситуация в моем регионе и городе?*
  2. *Грозит ли подтопление моей улице или району прямо сейчас?*
  3. *Где находится ближайший проверенный пункт временного размещения (ПВР)?*
  4. *Что собрать в тревожный чемоданчик и куда звонить (112 / оперативный штаб)?*

## 🧠 Интеллектуальный ML-модуль прогнозирования (XAI)

В ядре системы функционирует модель многошагового регрессионного анализа на базе **HistGradientBoostingRegressor (MultiOutputRegressor)**:
- **Горизонт опережения:** +1 час, +2 часа, +3 часа.
- **Входные параметры:** Временное окно уровней воды (см), скорость подъема ($\Delta h/\Delta t$, см/ч), ускорение, осадки (мм/ч), температура воздуха (°C), влажность грунта (%), удаленность от критического створа.
- **Explainable AI (XAI):** Объяснение вклада каждого гидрологического фактора (в процентах и единицах СИ) для предотвращения паники и обоснования действий спасательных служб.
- **Качество модели:** MAE = 2.02 см, RMSE = 2.53 см, $R^2 = 0.999$.

## 🚀 Быстрый запуск

### Способ 1: Docker Compose (Рекомендуемый)

```bash
cd /home/timur/projects/saqta
docker compose up --build -d
```
- **Портал Saqta.kz:** [http://localhost:3000](http://localhost:3000) или [http://localhost](http://localhost)
- **API Swagger Документация:** [http://localhost:8000/docs](http://localhost:8000/docs)

### Способ 2: Локальный запуск (Разработка)

#### 1. Бэкенд (Python 3.11+ / FastAPI):
```bash
cd /home/timur/projects/saqta
source .venv/bin/activate
PYTHONPATH=. uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```

#### 2. Фронтенд (Node.js / React Vite):
```bash
cd /home/timur/projects/saqta/frontend
npm run dev
```
Фронтенд запустится на [http://localhost:5173](http://localhost:5173).

## 🛡️ Безопасность и отказоустойчивость
- Хэширование паролей по стандарту `bcrypt`.
- Автономный fallback: при недоступности внешних ML-серверов или задержках сети система автоматически использует встроенный гидравлический расчетный модуль на базе данных Казгидромета.
- Никаких сторонних платных ключей и трекеров. Все данные и картографические тайлы работают полностью автономно.
