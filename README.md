# Saqta.kz — Государственная платформа мониторинга и прогнозирования чрезвычайных ситуаций

> **Хакатон Digital Urpaq**  
> **Сценарий:** Паводки и катастрофические подтопления на реке Есиль (г. Петропавловск, Северо-Казахстанская область).

---

## 🌊 О проекте

**Saqta.kz** — это полнофункциональный прототип (MVP) единой информационной системы ситуационного центра ДЧС СКО и МЧС РК для предиктивного гидрологического мониторинга. 

Платформа решает критическую проблему оперативного прогнозирования волны паводка (каскад: **Сергеевское водохранилище ➔ с. Покровка ➔ г. Петропавловск (Мост) ➔ пос. Заречный**) с заблаговременностью от 1 до 3 часов с помощью машинного обучения и гидравлического моделирования.

### Ключевые возможности MVP:
- **Интерактивная карта (MapLibre GL):** Отображение русла реки Есиль, гидропостов с цветовой индикацией уровней опасности (зеленый / желтый / красный) и зоны затопления поймы пос. Заречный без использования платных API-ключей.
- **Интеллектуальный ML-прогноз (XAI):** Расчет прогнозных отметок уровня воды на **+1ч, +2ч, +3ч**, динамический расчет комплексного индекса риска (0–100) и объяснение факторов влияния (скорость подъема, дельта до критического уровня, интенсивность осадков и снеготаяния).
- **Живой гидрограф (Recharts):** Совмещенный график фактической телеметрии за 48 часов, порогов «Предупреждение» и «Критический», а также пунктирной проекции прогноза ML.
- **Real-Time обновления (WebSockets):** Потоковая трансляция новых замеров телеметрии и экстренных оповещений на дашборд оператора без перезагрузки страницы.
- **Журнал диспетчера ДЧС и экстренные оповещения:** Обработка инцидентов дежурным оператором и интеграция с Telegram Bot API для рассылки оперативных бюллетеней.
- **Метеорологическая интеграция (Open-Meteo API):** Текущая температура воздуха, интенсивность дождя, оценка снеготаяния и увлажнения грунта для Петропавловска.
- **Интерактивный симулятор паводка:** Возможность на демонстрации запускать различные сценарии («Весенний паводок», «Критический перелив Сергеевки», «Штормовой ливень», «Штатный режим») с шагом или live-потоком каждые 3 секунды.
- **Автоматическая оперативная сводка ДЧС СКО:** Формирование официального гидрологического бюллетеня МЧС РК с зонами приоритетной эвакуации и печатной формой.

## 🛠 Технологический стек

- **Backend:** Python 3.11+, FastAPI, SQLAlchemy (SQLite с поддержкой PostgreSQL), Pydantic v2, WebSockets, Bcrypt, PyJWT, HTTPX.
- **ML Модуль (`/backend/ml`):** Изолированный интерфейс `predict_flood_risk` со строгим контрактом, поддержкой GradientBoosting (`flood_model.joblib`) и гибридным гидрологическим движком (Fallback Rule-Engine).
- **Frontend:** React 18, Vite, Tailwind CSS, Lucide React, Recharts, MapLibre GL.
- **Инфраструктура:** Docker, Docker Compose, Nginx (Alpine).

## 📍 Опорные гидропосты бассейна р. Есиль

В базу внесены 4 реальные станции Петропавловского гидроузла с критическими отметками паводка:

1. **«Сергеевское водохранилище»** (53.8824, 67.4111)  
   - Предупреждение: **800 см** (перелив через гребень)  
   - Критический: **1100 см** (максимальный перелив в истории 2024 г. — 425 см над гребнем)
2. **«Гидропост с. Покровка»** (54.2678, 68.8520)  
   - Предупреждение: **950 см**  
   - Критический: **1100 см**
3. **«Гидропост г. Петропавловск (Мост)»** (54.8753, 69.1389)  
   - Предупреждение: **940 см**  
   - Критический: **980 см** (выход воды на дорожное полотно)
4. **«Пос. Заречный (Зона поймы)»** (54.9120, 69.1650)  
   - Предупреждение: **880 см** (затопление прибрежной зоны)  
   - Критический: **950 см** (угроза жилым домам, объявление эвакуации)

## 🧠 Контракт ML-модуля (`/backend/ml/predictor.py`)

Модуль строго удовлетворяет контракту:
```python
def predict_flood_risk(telemetry_window: list[dict], thresholds: dict) -> dict:
    return {
        "risk_level": "low" | "medium" | "high",
        "risk_score": float,  # 0..100
        "forecast_1h": float,  # прогноз через 1ч (см)
        "forecast_2h": float,  # прогноз через 2ч (см)
        "forecast_3h": float,  # прогноз через 3ч (см)
        "horizon": "3h",
        "explanation": str,
        "factors": [
            {"name": "Скорость подъема воды", "weight": 0.55, "value": "+14.0 см/ч"},
            {"name": "Текущий уровень к порогу", "weight": 0.30, "value": "945 / 980 см"},
            {"name": "Осадки и снеготаяние", "weight": 0.15, "value": "12.4 мм/ч, +15°C"}
        ],
        "model_type": "ML GradientBoosting (v1)" | "Hybrid Hydrological Rule-Engine",
        "metrics": {"mae": 2.1, "r2": 0.94}
    }
```
- Если параллельный ML-агент обучает и сохраняет `flood_model.joblib`, бэкенд динамически подхватывает его.
- Если файла `.joblib` еще нет, автоматически активируется **Hybrid Hydrological Rule-Engine**, обеспечивающий непрерывность работы системы.

## 🚀 Инструкция по запуску

### Вариант 1. Запуск через Docker Compose (Рекомендуемый)

```bash
cd /home/timur/projects/saqta

# Сборка и запуск контейнеров
docker compose up --build -d

# Проверка статуса
docker compose ps
```
- **Фронтенд:** [http://localhost:3000](http://localhost:3000) или [http://localhost](http://localhost)
- **Бэкенд API Swagger:** [http://localhost:8000/docs](http://localhost:8000/docs)
- **WebSocket:** `ws://localhost:8000/ws`

---

### Вариант 2. Локальный запуск без Docker

#### 1. Запуск Backend (FastAPI):
```bash
cd /home/timur/projects/saqta
source .venv/bin/activate

# Запуск сервера uvicorn
PYTHONPATH=. uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```
При запуске бэкенд автоматически создает SQLite базу данных `saqta.db`, генерирует учетные записи и заполняет 48 часов исторической телеметрии.

#### 2. Запуск Frontend (Vite React):
```bash
cd /home/timur/projects/saqta/frontend

# Запуск dev-сервера
npm run dev
```
Фронтенд будет доступен по адресу: [http://localhost:5173](http://localhost:5173) (с настроенным проксированием `/api` и `/ws` на порт `8000`).

## 📡 Проверка основных эндпоинтов

- `GET /api/health` — статус здоровья сервиса.
- `GET /api/stations` — список станций с текущим уровнем воды и статусом риска.
- `GET /api/telemetry/3?hours=48` — историческая телеметрия для гидропоста Петропавловск.
- `GET /api/ml/predict/3` — инференс ML-модели для выбранного поста.
- `GET /api/weather/petropavlovsk` — оперативные метеоданные с Open-Meteo.
- `GET /api/reports/dchs-bulletin` — официальный бюллетень ДЧС СКО.
- `POST /api/simulation/step` — генерация следующего шага симуляции волны паводка.
- `POST /api/simulation/start` — запуск непрерывного live-потока телеметрии.

## 🏆 Демонстрационный сценарий для жюри (Demo Script)

1. Открыть платформу [http://localhost:5173](http://localhost:5173).
2. Обратить внимание на интерактивную карту реки Есиль: маркеры 4 гидропостов, траектория течения от Сергеевки до Петропавловска и зона подтопления поймы Заречного.
3. Кликнуть по посту **«Гидропост г. Петропавловск (Мост)»**: изучить график Recharts с порогами (940 / 980 см) и **пунктирной линией ML-прогноза на +1ч, +2ч, +3ч**.
4. В блоке **XAI (Explainable AI)** ознакомиться с факторами влияния модели (скорость подъема, осадки, снеготаяние).
5. В верхней панели симулятора нажать **«🚨 Крит. сброс Сергеевки»** и нажать **«+1 Шаг»** или **«Live-поток»**: наблюдать, как в реальном времени через WebSocket уровни воды начинают нарастать, график перестраивается, и регистрируется новое экстренное предупреждение в журнале инцидентов.
6. В журнале предупреждений нажать **«Telegram оповещение»** и **«Принять в работу»** от лица оператора ДЧС.
7. В правом верхнем углу нажать **«Сводка ДЧС»**: открыть официальный печатный бюллетень с перечнем приоритетных зон эвакуации (пос. Заречный, Кожевенный завод) и рекомендациями оперативному штабу.
